# service/

프론트+백엔드를 **서비스 단위**로 묶는 디렉터리입니다.  
학습용/샘플용 백엔드만 모아 둔 `../backend/` 와 역할을 나눕니다.

| 경로 | 설명 |
|------|------|
| [shop/](shop/) | 미니 커머스 (SSO + catalog + order + shop/admin 웹) |

새 서비스는 `service/<이름>/` 아래에 SSO·API·웹을 같은 패턴으로 추가하면 됩니다.

파이썬을 어디에 두면 좋은지는 루트 [README.md](../README.md)의 **Python (참고만)** 을 보세요. (지금은 서비스에 포함하지 않음)
